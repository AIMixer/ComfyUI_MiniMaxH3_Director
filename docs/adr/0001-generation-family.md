# 保留一个导演台，以生成系列选择 H3 与 Pika-H3

状态：采用，2026-11-02。

H3 与 Pika-H3 共用素材、分镜、缓存和导出管理；Pika 的适配器与固定配方需要和普通 H3 参数明确区分。为此在同一节点先选择生成系列，再选择该系列支持的任务，不另建一套节点或发布分支。

这样保留旧节点标识和端口，已有工作流与混合时间线继续可用；代价是前后端、导演包和缓存检查必须识别同一个系列，切换时显示实际生效的参数。旧 Pika 开关保留导入兼容，新交互统一使用系列选择。

Pika 保持原提示词进入原生条件编码；社区二采、续接、修脸等功能单独说明。原声用于生成的锁定约束默认关闭，不改变旧工作流仅在导出采用原声的语义。

内层调用原生节点时，需要遵守原生执行器的资源阶段边界，不能把整个导演台当作一个持续占用转换缓冲的推理阶段。该边界处理不通过强制卸载全部模型实现。
